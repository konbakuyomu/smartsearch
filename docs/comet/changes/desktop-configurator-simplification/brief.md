# 目标

把 Smart Search App 收敛为配置器：配置服务、显式测试、帮助安装电脑上的 CLI 和 Agent Skills。日常调用以外部 CLI 为主；App 关闭、更新或卸载后 CLI 仍独立可用。消除用户必须理解内部运行环境和多层检测才能完成操作的问题。

# 范围

- Windows 与 macOS 同步精简，保留当前原生外观、品牌、双语、键盘操作和配置草稿保护。
- 导航收敛为“配置”“测试”“CLI 与 Skills”“设置”。移除独立概览和常驻活动工作台；测试结果与必要错误详情留在对应操作处。
- 删除“启用内置命令”“复制内置 CLI 调用”及 App 后端公开 CLI 分发分支；内部仅保留配置、测试与安装管理所需私有进程。外部 CLI 安装、更新和 Skills 调用继续使用 App 目录之外的已有独立实现。
- Skills 使用勾选框表达本次安装/更新目标，移除把选择伪装为开启/关闭状态的开关。选中至少一个目标后，主按钮立即可用；点击一次完成可信来源检查、备份和安装/更新，没有变化则明确显示已是最新。取消勾选不会卸载文件。
- 合并“检查最新 Skills”“刷新本机状态”和分开的准备步骤；日常页面不要求先手动检测。移除逐行“文件详情”和单独偏好/环境管理弹窗，必要路径、备份及错误信息按需查看。
- CLI 区只显示版本/安装状态和当前需要的一个动作（安装、更新或重试）。检测、补依赖、来源保护、实际运行验证在操作内部完成；不再提供环境检测/验证按钮阵列。
- 设置保留语言、外观、配置目录、App 更新和关于。App 更新只保留一个随状态变化的主操作；去掉常驻旧版迁移说明、内置引擎/CLI 路径、开发连接及重复更新入口。必要异常提示只在对应问题发生时出现。
- 同步当前产品定位、协议、两种语言文案、使用文档及相应回归；精简相关失效控件、处理函数和不再使用的状态，而不改公开 CLI 的功能。

# 非目标

- 不删减公开 CLI 的搜索/文档/抓取/研究能力，不重写安装器、签名或自动更新框架。
- 不删除用户配置、Key、结果、日志、已安装 Skills、历史同名副本或外部 CLI；取消勾选仅改变本次目标。
- 不引入要求先安装外部 CLI 才能打开配置器或测试服务商的依赖。私有配置/测试进程不作为用户 CLI 使用或加入 PATH。
- 不改变已发布版本、本机正式安装和个人 Agent 目录；候选阶段使用隔离测试目录。发布和替换安装另行处理。
- 不批量删除文件/目录；移除界面及代码分支不等于清理用户磁盘或历史证据。

# 验收示例

完整场景写入 specs/desktop-configurator/spec.md。重点可复现路径是“本次启动还没有成功联网检查 → 选择未安装的 OpenCode → 按钮可点 → 点击后完成检查与安装，或显示可重试错误”，而非通过绕过校验让按钮亮起。

# 约束与不变量

- 基线 main 0af19548b2df7e0e6bf2df64a831b909a1706cd3；隔离目录 smartsearch-desktop-configurator-simplification、分支 codex/desktop-configurator-simplification。
- App 保留原生配置/测试辅助进程和共享核心，不额外制造外部 CLI 子进程适配层。它不公开搜索命令、不供 Agent 调用、不建立指向 App 的 PATH/symlink。
- Skills 来源仍为经 SHA512 和归档边界验证的官方 stable npm 包；未知来源、路径链接/越界、目标变化与写入失败不能因精简而被忽略。
- 保留来源管理器、只更新 Smart Search、并发写入互斥、未保存草稿、任务取消与安全重启；失败时给一个可执行的下一步。
- 作者已验证的原生界面/安装基线保留其历史证据；此次变更以当前提交的测试和构建为准，GUI 由用户验收。

# 决策

- 用户已明确要求配置器定位、帮助安装外部 CLI、修 Skills 主操作不可用、全面精简。旧“完整搜索工作台”和内置 CLI 导出不再作为保留理由。
- 外部 CLI 独立路径、安装、更新和 Skills 调用链已存在，复用其底层实现；移除另一条内置 CLI 入口，避免增加新的安装系统。
- 配置和测试紧密共享原生主窗口、模型和后端状态，本 change 不拆 Supervisor，避免多个写入者同时改核心文件；已并行完成只读事实核验。
- 用户在本轮结构化确认中明确选择“确认，按这套方案实施（推荐）”：采用四页导航、勾选目标+单一安装/更新动作、操作内部检测、设置单一 App 更新入口；同步修改 Windows/macOS 并运行 CI。内部配置/测试辅助进程及备份/数据保护保留，交付测试候选，不替换当前安装或发布稳定版。

# 待解决问题

无。完整方案已获用户明确确认；稳定发布和本机安装替换不在本轮授权范围。

# 验证预期

- Skills 的选择、首次启动/仅缓存、检查失败重试、相同内容无写入、目标变化和并发保护有可运行回归；两端按钮策略一致。
- App 私有入口不能变成公开 CLI，cli.enable 不再发布 App 路径；外部 CLI 安装与现有 npm/mise 更新合同回归。
- 全面核对两端可见按钮、导航和双语文案，不只隐藏某一个入口；必要状态及取消/安全保护仍工作。
- 运行适用 Python/native 模型检查、Windows 构建、现有多平台 CI；个人配置/安装/Skills 不作为测试夹具。
- 新只读 Verifier 覆盖全部场景；提供用户可照做的最短 GUI 检查，不把构建成功当作 GUI 实测。
