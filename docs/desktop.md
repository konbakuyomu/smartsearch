# Smart Search 桌面端

![Smart Search](../assets/branding/smart-search.png)

## 安装和打开

在 [v0.1.20 Release](https://github.com/konbakuyomu/smartsearch/releases/tag/v0.1.20)
下载对应架构的安装包，Windows x64、Windows ARM64、macOS Apple 芯片和 macOS Intel 各一个，旁边附 `SHA256SUMS.txt`。
它安装到当前用户的应用目录，自带运行环境，无需先安装 Python、Node 或全局 CLI。
安装包尚未签名，macOS 未公证。macOS、Windows ARM64、干净虚拟机和完整 DPI 矩阵尚未完成实机验收。

安装后从开始菜单打开 **Smart Search**。已有配置会被复用；没有配置时，概览会提示缺少主搜索、文档检索或网页读取能力。

## 六个页面

| 页面 | 用途 |
| --- | --- |
| 概览 | 查看配置是否齐全，以及下一步该配置什么 |
| 服务商 | 填写地址、Key、模型和高级参数；测试草稿、预览、保存 |
| 搜索与研究 | 搜索、读取网页、站点地图、查文档、生成离线计划或在线研究；复制和导出结果 |
| 活动 | 查看实际阶段、服务商、模型、耗时和终态；取消本 App 启动的任务 |
| AI 接入 | 查看内置与外部 CLI 路径/版本，复制调用方式，选择 Skills 安装目标 |
| 设置与关于 | 切换配置目录、添加活动观察目录、调整主题、重置健康状态和手动检查更新 |

服务商页遵循“编辑草稿 → 测试草稿 → 保存”。密钥框留空或删空表示保留旧值；只有明确勾选清除才删除保存值。
环境变量覆盖的字段会显示有效来源，App 不覆盖它们。草稿测试和真实搜索可能产生服务商费用，启动 App 或查看本地状态不会自动执行这些测试。

## CLI 与 App 的关系

- CLI 和 App 可以独立运行。App 自带私有后端，外部 CLI 不通过 App 执行。
- 使用同一个配置目录时，Key、地址和模型配置互通；保存的新配置用于下一次调用，正在运行的任务保留启动时的快照。
- 默认 Windows 配置路径为 `%LOCALAPPDATA%\smart-search`，既有 legacy 路径仍受支持；显式 `SMART_SEARCH_CONFIG_DIR` 或 App 中选择的目录可以用于隔离。
- App 更新不覆盖独立 npm CLI。要在 App 看到终端/AI 的活动，请将外部 CLI 升级到 0.1.20；旧 CLI 保持可用，但没有新活动事件。
- 如果使用 App 内置 CLI 的绝对路径，关闭窗口不影响调用；卸载 App 会移除该内置可执行文件。独立安装的 npm CLI 不受影响。
- 不同进程继承的环境变量可能不同，因此相同配置文件不保证两个进程的有效环境完全一致。

## 活动与退出

活动页每两秒刷新，只观察当前或明确添加的配置目录。默认记录运行元数据，不保存查询、回答、请求头或 Key。
已结束记录默认最多保留 7 天 / 1000 条；清除活动历史不会删除配置、研究证据或导出文件。

有 App 任务运行时关闭窗口，可以选择后台继续、取消任务并退出或返回。
后台窗口可从通知区域恢复，再次启动也会唤起同一窗口。App 不会取消终端或 AI 独立启动的 CLI 任务。
心跳过期显示“状态未更新”，不把缺少完成记录误报为成功。

## 更新与卸载

从发行页手动下载新安装器，先处理 App 的任务并退出再升级。安装器检测到 App 仍在运行时会拒绝覆盖私有资源。
卸载保留共享配置、CLI 数据、研究证据和用户导出结果。

构建与协议说明分别见 [desktop/README.md](../desktop/README.md) 和 [desktop/PROTOCOL.md](../desktop/PROTOCOL.md)。
